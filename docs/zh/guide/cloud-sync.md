# 账号与云同步

Web Resume 仍然以本地使用为主：不登录也可以编辑、预览和导出 PDF。在主站中，你可以选择使用云乐坊账号登录，把可移植的 YAML 简历保存到自己的云乐坊云盘空间。

## 首次保存与自动同步

1. 从桌面侧栏或移动端底部导航进入“我的”。
2. 使用云乐坊账号登录。
3. 为当前简历填写文件名，点击“新建并保存”。
4. 首次保存后，停止输入约 2 秒会自动同步。

格式暂时无效的 YAML 草稿也会保存，并明确标记为“待修正草稿”。云端文件包含原始可移植 YAML 和必要元数据；本机姓名、电话、邮箱等覆盖字段不会上传。

## 多设备与冲突

你可以从“我的”页面的 **Web Resume** 区域或“选择简历来源”对话框打开任意云端简历。Web Resume 使用乐观版本控制：如果另一台设备已经保存更新版本，当前修改会生成一个冲突副本，不会静默覆盖新内容。

## 空间、回收站与退出登录

云端简历占用云乐坊账号共享的云盘配额。删除会先移入回收站，30 天内可以恢复。退出登录会保留本机编辑内容和个人资料；“清除本机数据”只清除当前浏览器的 Web Resume 数据，不删除云端文件。

云端简历为私有文件，不提供公开分享链接。存储未提供端到端加密，请勿在简历中保存密码、API 密钥或访问令牌。

GitHub 不作为自动同步源。未来可以提供显式导入/导出，但不会把 GitHub 变成简历数据的唯一真相源。
