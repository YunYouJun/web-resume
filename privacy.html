隐私政策

Web Resume 以本地处理为主。我们只处理提供简历预览、编辑和导出所需的数据，并尽量让数据去向保持清晰。

更新日期：2026 年 9 月 3 日

我们处理哪些数据

  • 简历内容：你输入的 YAML 地址及其返回内容会在浏览器中获取、校验和渲染。
  • 本地资料：姓名、电话、邮箱、编辑器内容、当前与最近使用的简历、界面设置保存在浏览器本地存储中。姓名、电话、邮箱等本地覆盖字段不会随云同步上传。
  • 可选账号与云同步：登录云乐坊账号后，简历原始 YAML、文件名、模板、校验状态、版本和保存时间会保存在你的云乐坊云盘空间；会话使用安全 Cookie 维持。
  • 基础使用数据：站点通过 Google Tag Manager 加载站点所有者配置的统计工具，用于了解页面使用情况和改进产品。

数据如何流转

不登录也可以完整使用本地编辑与导出。只有你登录并首次为当前简历命名保存后，Web Resume 才会把简历 YAML 同步到云盘；随后会在停止输入约 2 秒后自动保存。并发版本冲突会生成副本，不会静默覆盖。

退出登录不会删除本机内容。云端删除先进入回收站并保留 30 天；“清除本机数据”只清除当前浏览器中的 Web Resume 数据，不删除云端简历。

当你加载外部 YAML、引用 GitHub 项目信息或打开外部链接时，相应服务会收到正常网络请求，包括 IP 地址、浏览器信息和所请求的网址。它们会依照各自的隐私政策处理数据。

分享与导出

分享链接会包含简历 YAML 地址。请勿分享包含访问令牌、临时凭据或不希望公开的地址。PDF 导出由浏览器或操作系统的打印能力完成，生成文件不会经过 Web Resume 服务器。

第三方服务

  • Google 隐私政策：标签管理及可能由标签加载的使用统计。
  • GitHub 隐私声明：源码托管、问题反馈及可选的公开仓库信息请求。
  • 云乐坊账号与云盘：可选的统一登录、私有简历存储和共享账号空间配额。
  • 你主动提供的简历托管服务：用于返回 YAML 和其中引用的图片等资源。

安全与选择

外部简历中的富文本和动态链接会在渲染前经过安全清洗。云端简历为私有标准存储，不提供公开链接，也不提供端到端加密；请勿保存密钥、令牌等机密。你可以关闭“使用我的资料覆盖简历信息”，退出账号，或单独清除本机数据。
